# Support

Chronos is experimental and maintained on a best-effort basis.

## Where to ask

- **Usage and design questions:** use GitHub Discussions.
- **Reproducible defects:** use the bug report issue form.
- **Feature proposals:** use the feature request issue form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not disclose exploit details publicly.
- **Nox compiler/runtime defects:** first confirm the behavior with a focused reproducer, then record the Chronos impact.

Include the Nox version, operating system, architecture, backend, smallest reproducer, expected result, and actual result. Remove secrets and private job payloads from all logs.

The project does not currently offer paid support, response-time guarantees, migration support for unreleased APIs, or debugging for modified Nox runtimes.
